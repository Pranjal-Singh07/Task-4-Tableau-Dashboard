# Task 4 – Sales & Financial Performance Dashboard

## Objective

The objective of this task was to design an interactive dashboard for business stakeholders using Tableau.

## Tool Used

- Tableau Public

## Dashboard Components

The dashboard includes:

- Total Sales KPI
- Total Profit KPI
- Total Cost KPI
- Total Orders KPI
- Sales Trend Over Time
- Sales over Category
- Profit by Country
- Device Type, Country and Category filters
- Navigation between Overview, Sales Analysis and Profit Analysis
